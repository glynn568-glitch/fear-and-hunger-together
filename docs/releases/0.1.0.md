First public beta.

**Download `FearAndHunger-Together-0.1.0.zip` below**, unzip it anywhere, and double-click **Fear & Hunger Together**. Every player needs their own copy of Fear & Hunger (Steam or itch) and this same version of the mod.

The first time, Windows may say "Windows protected your PC" because the program isn't signed. Click **More info**, then **Run anyway**.

- Up to four players, each from their own copy; host online from the title screen and send the link.
- AI partners that play a character by the same rules you do (Claude Code, an Anthropic API key, or a local model in Ollama).
- Shared fights, shared world, revival at ritual circles, saves for everyone at a bed.

Found a bug? Press Ctrl+Shift+B in the game and paste what it copies into a new issue.
