**Download `FearAndHunger-Together-0.1.5.zip` below**, unzip it anywhere, and double-click **Fear & Hunger Together**. Everyone in a game needs this same version (0.1.4 players are asked to update).

- **Players whose game files differ can now play together.** Until now any difference in the game's data files kept two players apart, even on the same release of the game: a mod installed at some point, a changed install, or a copy (on a Steam Deck, say) that hashes differently. Now the same release of the game is enough. The joiner is told once that their files differ, and the host's copy decides what is shared, so both sides stay in step.
- A different release of the game is still kept apart, with a message that says so.

Found a bug? Press Ctrl+Shift+B in the game and paste what it copies into a new issue.
