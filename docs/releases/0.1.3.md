**Download `FearAndHunger-Together-0.1.3.zip` below**, unzip it anywhere, and double-click **Fear & Hunger Together**. Everyone in a game needs this same version (0.1.2 players are asked to update).

A hotfix: **you can paste a friend's link into Together again.** An invisible strip the game uses for error messages sat across the middle of the screen, right on top of the link box, and swallowed every click there. The box never got focus, so Ctrl+V and typing went nowhere. Clicks now go through the strip, and right-click → Paste works in the mod's text boxes too.

Nothing else changed. Party mode and more are on the way in the next update.

Found a bug? Press Ctrl+Shift+B in the game and paste what it copies into a new issue.
