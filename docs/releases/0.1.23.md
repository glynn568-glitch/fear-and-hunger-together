**Download `FearAndHunger-Together-0.1.23.zip` below**, unzip it anywhere, and double-click **Fear & Hunger Together**. Everyone in a game needs the same version.

Your saves are in your old version's `app\data` folder. To keep them, copy that folder into the new `app` folder, or unzip the new version over the old one.

Changed:

- **The lobby menu** shows where things stand on each line. The host sees Run:, As: and Start, and Start names whoever it's waiting on. Everyone else has one As: line, and choosing who you come in as marks you ready. A greyed-out character shows who has it.
- **Your saves from other runs** now show in your list too. Pick one and that character joins the host's run as you saved them: level, gear, items and wounds. The world and story stay the host's, so that run's progress stays behind, and the game asks before you bring one in. You start next to the host.
- **When the lobby can't do what you asked**, it says why, for example "Cahara is taken by Ann." Before, nothing happened.
- **The hounds in the first yard** wait until everyone is in the run, so whoever gets in first isn't attacked while a friend is still in the opening.
- **A friend on another version** is told so when they try to join, and the host's screen says who was turned away and which versions you each have.
- **Each PC keeps its own log** of the lobby and the session, and a bug report includes the connection, this PC's saves, and the error if the game stopped on a red error screen.

Fixed:

- **The character picker in the opening** now takes the character you chose in the lobby by itself. It used to wait for a button press, so with a mouse or a touchscreen there was no way past it.
- **A join link that opens Together** now has Join selected. Pressing A or Enter there used to start hosting instead.
- **If the host's link stops working**, a friend is told after about 30 seconds to ask for the new one. Before, it said "Trying again" forever.
- **A save that doesn't write** now says so, yours and the one made alongside a friend's. It used to only buzz, or say nothing.
- **The name box** takes A and B on a controller. On a Steam Deck, the message about the name says Steam+X opens the keyboard.
- **"Press R to carry on"** after a crash can be clicked too.
- **Saves stay in order** when one PC's clock is wrong.
- **Your save list** shows only the saves on your own PC. A friend who typed a name someone had used on that host before could see that person's old saves. Saves you made as a friend on 0.1.8 or earlier and haven't loaded since are still on the host's PC, in `app\data\saves\players\<your name>`: copy them into the same folder on yours.
- **A save that the host's PC couldn't keep the world for** goes back to the save that was in that slot, and you're told to save again. Before, it replaced your last good save and loading it started an empty world.
- **Opening the game twice** no longer starts a second copy, and the same game open in two tabs no longer knocks itself off over and over.

Found a bug? Press Ctrl+Shift+B in the game and paste what it copies into a new issue.
